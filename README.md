# Special Design

A responsive and interactive landing page built with HTML, CSS, and Vanilla JavaScript. The project focuses on creating a modern user experience through dynamic theme customization, persistent user preferences with Local Storage, animated sections, dynamic backgrounds, smooth scrolling navigation, and an interactive image gallery.

## ⚙️ Customization Guide

### Change Theme Colors
1. Open `JS/master.js`
2. Find the `themeColors` array
3. Modify the color values (hex or rgb)
4. Save and refresh the browser

### Add Custom Background Images
1. Add your images to the `imgs/` folder
2. Open `JS/master.js`
3. Update the `backgroundImages` array with new image paths
4. Save and refresh

### Modify Sections
- Edit sections in `index.html`
- Style with `CSS/master.css`
- Add interactivity with `JS/master.js`
