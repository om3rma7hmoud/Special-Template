# Special Design

A responsive and interactive landing page built with HTML, CSS, and Vanilla JavaScript. The project focuses on creating a modern user experience through dynamic theme customization, persistent user settings, smooth navigation, animated components, and responsive layouts.

---

## Preview

Special Design is a multi-section agency landing page that demonstrates front-end development fundamentals and interactive user interface techniques using pure JavaScript without external frameworks.

---

## Features

### Theme Customization
- Multiple theme colors
- Instant theme switching
- Selected theme stored using Local Storage
- Settings reset functionality

### Dynamic Backgrounds
- Random background image rotation
- Enable/Disable background randomization
- User preference persistence

### Navigation
- Smooth scrolling between sections
- Fixed navigation bullets
- Responsive navigation menu
- Mobile-friendly layout

### Interactive Components
- Animated skill progress bars
- Gallery image popup viewer
- Dynamic DOM element creation
- User preference management

### User Experience
- Responsive design across devices
- Clean and modern UI
- Persistent settings using Local Storage
- Smooth animations and transitions

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/special-design.git
```

Navigate to the project directory:

```bash
cd special-design
```

Open the project:

```bash
index.html
```

Or simply open `index.html` in your browser.
